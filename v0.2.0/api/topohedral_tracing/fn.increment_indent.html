pub fn increment_indent()
Expand description

Increase the indentation level of the current thread by one.

Subsequent log messages on this thread are indented one level further. Pair every call with a matching decrement_indent; prefer trace_scope! or trace_fn, which pair them for you via IndentGuard and cannot leak on an early return or a panic.
